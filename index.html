Hello! This is a simple color lookup site for the "XL-Byg Johannes Fog Lyngby" wall of jotun colors examples.

to use it, just type the color you are looking for in the box aabove and it will show you where it is located on the wall.

if you find an error, for instance if a color is wromg or things have been moved around, feel free to send me an email at color@dendersen.dk explaining the issue.
Alternatively, submit an issue on the project's GitHub page here.
Enjoy!
